QuickDL Privacy

This page describes the main data flows used by the current QuickDL application.

Anonymous visitor identity

QuickDL uses a first-party vexdou_visitor cookie to keep an anonymous browser identity stable. This identity is used to associate that browser with its download history and jobs.

Download history

Completed download records can be stored in QuickDL's database so the same visitor can see their History after returning to the site. Downloaded media files are stored temporarily on the server and are removed by the configured cleanup process.

Accounts and payments

When Free Mode is open, QuickDL does not require sign-in, sign-up, credits, or payments for downloads. Account and payment interfaces are hidden from users. If Free Mode is later closed by the administrator, the account and payment features can be enabled again.

Support messages

If you use the contact form, the name, email address, and message you submit can be stored so QuickDL support can respond.

Third-party media platforms

Download requests are sent to the public media URL you provide and processed by the downloader engine. QuickDL does not promise access to private, DRM-protected, CAPTCHA-protected, or login-only media.

Contact

Use Contact QuickDL or the WhatsApp support button when it is open.
