# QuickDL v16

QuickDL v16 is a public-media downloader with a server-side credit wallet, LIVE PayPal checkout, unlimited-user admin controls, download recovery, revenue reporting, diagnostics, and a full admin control center.

## Core features
- 50 monthly free credits by default
- Configurable credit cost per download
- Purchased credits do not expire
- Admin can add/remove any amount of credits
- Admin can enable/disable Unlimited per user
- LIVE PayPal Orders + Capture + webhook verification
- Download queue with recovery and error center
- Public media only; no private/login/DRM/CAPTCHA bypass
- Admin sections: Overview, Users, Credits, Payments, Downloads, Errors, Settings, Audit, System
